# النشر وحل المشكلات

## التاريخ

نُشر واختُبر سابقاً، وكان متاحاً على Google Play لكنه غير متاح هناك حالياً. لا تتوفر تواريخ موثقة أو أسباب الإزالة أو أرقام الاستخدام.

## البيئة المحلية

أنشئ PostgreSQL فارغة ثم انسخ api/.env.example إلى api/.env واضبط DATABASE_URL وJWT_SECRET جديداً بطول 32 حرفاً على الأقل وكلمتي ADMIN_PASSWORD وDEMO_PASSWORD بطول 12 على الأقل. اجعل SEED_DEMO_DATA=1 للعرض المؤقت فقط. تضيف التعبئة سائقاً وتجاراً اصطناعيين، ويضيف bootstrap-customer عميلين. اضبط بيئة الإدارة وAPI على 2007 وبيئات العميل والسائق حسب المحاكي أو الشبكة. أعد إعداد الخرائط وFirebase والتوقيع بصورة مستقلة.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

لم تُفحص أجهزة وبناء أندرويد والخرائط وFirebase وإشعارات عدة أجهزة والتحديثات المالية المتزامنة. نجح التكرار التسلسلي فقط. أوقف API قبل توليد Prisma أو الاستعادة على Windows لتجنب قفل DLL.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
