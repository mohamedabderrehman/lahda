# جولة موثقة

جولة في لقطات فعلية للواجهة. ليست فيديو متصلاً أو فحص جهاز موبايل. ينفذ أمر القبول تسلسل الخادم ببيانات اصطناعية؛ راجع سجل التحقق.

يختار العميل العنوان والمنتجات ← يحسب الخادم الطلب ← يجهز التاجر ← يقبل السائق العرض ← تُحدَّث متابعة التوصيل ← تسوي الإدارة النقد وقيود الدفتر.
